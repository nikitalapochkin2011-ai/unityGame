ЕЩЁ ОДИН ЭТАЖ — запуск на Windows

1. Распакуйте архив, например в C:\UnityProjects\.
2. В Unity Hub: Проекты → Добавить → Добавить проект с диска.
3. Выберите C:\UnityProjects\unityGame (внутри должны быть Assets, Packages, ProjectSettings).
4. Откройте проект установленным Unity. Проект подготовлен для Unity 6.3 LTS;
   при использовании 6.6 согласитесь на обновление копии проекта.
5. Дождитесь импорта. В верхнем меню редактора:
   Ещё один этаж → Создать или открыть игровую сцену.
6. Нажмите треугольник Play сверху, затем Играть в игровом окне.

Если кнопки не реагируют: Edit → Project Settings → Player → Other Settings →
Active Input Handling → Input Manager (Old) или Both. Перезапустите редактор.

Не нужно создавать новый проект или копировать файлы по отдельности.
Сцена создаётся встроенной командой, все компоненты связываются автоматически.
Подробности и сборка Android: README.md.

Ядро C# проверено отдельно. Запуск в Unity и Android-сборка пока не проверены.
