# Первые четыре шага подготовки Android

Доступ к аккаунту Unity для этой подготовки не нужен. Аккаунт остаётся на вашем компьютере. Проект подготовлен для Unity 6000.6.7f1; здесь нет готового APK/AAB и нет ключа подписи.

## 1. Установить инструменты на вашем компьютере

Закройте Unity Editor. Откройте Unity Hub → Установки → рядом с 6000.6.7f1 нажмите Управление → Добавить модули.

Отметьте Android Build Support и вложенные пункты Android SDK & NDK Tools и OpenJDK. Дождитесь полной установки. Если пункта «Добавить модули» нет, не переустанавливайте всё наугад: покажите меню Управление, чтобы определить способ установки редактора.

## 2–4. Применить подготовленные настройки одной командой

1. Скачайте свежий ZIP репозитория и распакуйте в новую папку. Старую рабочую папку сохраните.
2. Запустите OPEN_GAME.cmd, дождитесь импорта и подготовки SDF-шрифтов. Если появится TMP Importer — нажмите Import TMP Essentials.
3. В верхнем меню Unity выберите **Ещё один этаж → Android → Подготовить проект для Android**.
4. Команда сохранит настройки, проверит наличие сцены Game, поставит её первой в глобальном списке сборки и при установленном Android-модуле переключит платформу. Переключение может занять несколько минут из-за переимпорта.
5. При необходимости откройте **Ещё один этаж → Android → Проверить настройки Android**. Отчёт также записывается в Console.

Команда задаёт:

| Настройка | Значение |
|---|---|
| Название по умолчанию | Ещё один этаж |
| Package Name по умолчанию | com.nikitalapochkin.onemorefloor |
| Версия по умолчанию | 1.0.0 |
| Bundle Version Code | Не меньше 1, существующий больший код сохраняется |
| Ориентация | Portrait |
| Scripting Backend | IL2CPP |
| Архитектура | ARM64 |
| Minimum API | 26 |
| Target API | Automatic, из установленного SDK |

Своё ранее выбранное имя пакета, название и версию команда сохраняет. Имя пакета автоматически меняется только с исходного шаблонного `com.independentstudio.onemorefloor` либо с пустого значения. Перед первой публикацией выберите окончательный идентификатор: после публикации его нельзя изменить для того же приложения. Доступность имени в Google Play здесь не проверена.

Если Android Build Support не установлен, настройки всё равно сохранятся, а переключение платформы не произойдёт — окно объяснит, какие модули добавить. После установки выполните команду ещё раз. Она не меняет пароли, аккаунт, keystore и подпись и не начинает сборку автоматически.

Отчёт проверяет папки встроенных SDK/NDK/OpenJDK, а не фактическую работоспособность инструментов. Если используете свои SDK/NDK/JDK, проверьте их отдельно в Edit → Preferences → External Tools. По умолчанию удобнее использовать установленные через Hub инструменты.

Стандартный профиль Android использует глобальный список сцен. Если создали собственный Build Profile со своим списком, проверьте Game и в нём. Target API перед отправкой должен соответствовать действующим требованиям вашей Play Console: Automatic не является гарантией этого соответствия.

## Что дальше

После первых четырёх шагов нужно отдельно собрать тестовый APK, установить на телефон и проверить игру. Затем создать/выбрать собственный ключ подписи и собрать AAB для тестового канала Google Play. Сохранение настроек не доказывает успешную сборку.

В облачной среде Unity Editor и Android-модули отсутствуют: выполнение этой команды в Unity, переключение платформы, сборка и запуск на Android здесь не проверены.
